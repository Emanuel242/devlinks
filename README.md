# DevLinks

Projeto desenvolvido durante o curso Discover da Rocketseat.

## 🚀 Tecnologias

* HTML
* CSS
* JavaScript
* Git e GitHub

## 💻 Projeto

O DevLinks é uma página que reúne links pessoais em um só lugar, funcionando como um cartão de visitas online.

## 📚 Sobre o projeto

O projeto foi desenvolvido para praticar os fundamentos de desenvolvimento web, principalmente HTML, CSS, JavaScript e Git.
